# NezuUI attribution

Presentation code and CSS in this directory are adapted from
[tqmane/NezuUI](https://github.com/tqmane/NezuUI), commit
`69e156bbb91fdf6fb14f34cabcba8a8b3b4aa0b4`:

- `src/components/FloatNotice.tsx`
- `src/components/Toggle.tsx`
- `src/components/Avatar.tsx`
- `src/components/Badges.tsx`
- `src/components/nezuui-components.css`
- Composer surface geometry from `src/components/MessageComposer.tsx` and
  `src/components/message-composer.css`
- Settings navigation, selection indicators, heading scale, and panel geometry
  adapted from `src/App.css` catalog layout

NezuUI's original inventory and several interaction patterns were researched
from the MIT-licensed [Vyline](https://github.com/nezumi0627/vyline). Its composer
was adapted from a Vyline source archive. These adaptations keep presentation
independent from product APIs, stores, and protocol code. Catalog-only sending,
recording, sample stickers, and AI fallback behavior are not included.
