# 通話レイアウト

## 契約

- 相手と自分の映像には薄い枠・名前を付ける。
- フォーカス表示の小窓はポインターで領域内を移動できる。6pxを超えるドラッグとタップを分離し、矢印キーで移動、Enter/Spaceで入替。
- 分割、3人以上での一覧、固定対象と表示順の選択を提供する。媒体要素の親・ref・streamを表示変更の際に再作成しない。
- 音声のみの場合は非表示の映像操作へフォーカスしない。短い画面で先頭を画面外に押し出さない。
- グループの合成表示テストとLINEでの複数参加者の実測は区別する。

## 実装

`apps/desktop/src/components/call-video-stage.tsx` は表示のみを担当する。
映像取得・送受信・終了処理は既存の `useCallVideo.ts` の責務を保つ。
参加者IDをキーにした固定した親要素にCSSの位置・order・gridを適用する。
1対1はpeer/selfの2タイル。グループは実参加者IDごとのcanvasと自分のプレビューを同じステージへ渡す。

## 検証

ルートで `bun run build` → `bun Vyline/apps/desktop/tests/serve-call-ui.ts`。
表示された `/lifecycle` でライフサイクル・入替・ドラッグ・分割・順序・合成4タイルの回帰テスト。
`/lifecycle?preview-controls` で実ポインター操作、`?preview-group` で合成4人の表示確認。
320/768/1024/1440px幅と短い横画面を確認する。これらは実カメラやLINE接続を使わない。

参照: [React: Preserving and resetting state](https://react.dev/learn/preserving-and-resetting-state)。

## 2026-09-07 グループUIの追加要件

- Zoomのギャラリーとフォーカス表示を参考に、人数が増えてもタイルを押し潰さない。
- スマホのギャラリーはページとスワイプ、デスクトップは画面寸法に応じた列数とページ操作を提供する。
- タップ／クリックで映像をフォーカス・固定し、固定解除も提供する。並べ替えや固定を相手の表示へ送信しない。
- 操作ボタンは常時到達可能にし、ページ切替・固定・回転で媒体DOMを作り直さない。
- 音声通話は参加者が多ければ縦スクロールできるカード一覧とし、名前・ミュート・終了操作を隠さない。
- 発話者情報がないのに自動話者判定を表示しない。実装していないZoom機能を示唆しない。
- 1/2/3/4/9/16参加者の合成表示、タップ・ドラッグ区別、スワイプ・キーボード、参加者減少時の固定解除を検証する。

参照: [Zoomのビデオレイアウト](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0063672)、
[Zoomの固定操作](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0065767)。

### 実装・確認（2026-09-07）

- ResizeObserverで実ステージ寸法を測り、ギャラリーは最大4人、幅600px以上かつ高さ300px以上では9人、幅960px以上かつ高さ400px以上では16人ずつ表示する。
- フォーカスは狭いステージで大映像＋下部2人、広いステージで大映像＋右側最大4人。残りは同じページ操作で表示する。固定解除で一覧へ戻る。
- 水平方向60px以上かつ縦移動の1.5倍以上のスワイプでページを変更する。縦スクロールはページ変更に使わない。ボタン操作も常設する。
- 非表示ページも同じ媒体DOMを維持する。参加者減少時は有効なページに戻す。自動話者判定は行わない。
- 常設ブラウザ回帰で固定／解除、横／縦タッチ、16人4列、9人の4/4/1ページ、媒体ref／stream／canvas画素の維持、音声30人の末尾スクロールと終了操作の可視性が成功。
- 実ブラウザで320/375/414/768/1024/1440pxの表示境界を確認。タッチ回帰は合成イベントで、実タッチ端末の指操作とは区別する。

## 2026-09-07 追加: 通話中のトークと可変分割（ユーザー依頼）

- 映像の分割位置をドラッグで調整する。フォーカスの主映像／参加者列と、分割レイアウトの主境界を対象にし、キーボード操作・リセットも提供する。
- 大画面はトーク領域を塞ぐモーダルをやめ、独立した通話ペインを同じ画面に追加する。ペイン幅もドラッグ調整でき、トーク入力・スクロールを妨げない。
- スマホでは初期の全画面通話から小さい「通話へ戻る」表示へ畳んでトークを操作できる。戻す操作と終了操作を残し、記録中の表示を隠さない。
- 畳む／戻す、ペイン幅・映像比率の変更、画面回転でCallController、録音・録画、媒体DOMやstreamを再作成しない。
- 新しいレイアウトの検証には生成媒体を使う。実カメラ・マイクや新たなLINE発着信を必要としない。
