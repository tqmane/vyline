# 通話記録の管理

## 目的

設定の専用項目から、自分の通話記録を探して再生・ダウンロード・削除する。
サーバー保存APIは `SPEC-call-recording.md` を正本とする。

## 契約

- 日時、通話種別、記録種別、時間、サイズ、保存状態、保存期限を一覧表示する。
- 未記録・記録中・送信中・完了・中断／失敗を混同しない。空状態、取得失敗と再試行も表示する。
- ブラウザー標準の音声／映像controlsで再生し、全ファイルを先にRAMへ読み込まない。
- DLは認証を維持し、安定したファイル名と正しいContent-Typeを返す。
- 削除は対象を示して確認し、一覧・ファイル・容量表示へ反映する。
- 自動録音・録画の設定と、初期30日／無期限を含む保持設定を用意する。
- アカウント切替時に旧アカウントのデータ・要求結果・再生・ダウンロードを持ち越さない。
- 通話の診断情報はサニタイズ済みの情報に限定し、鍵やパケット内容を表示しない。

## 構造・検証

既存SettingsSectionsへ専用の小さいパネルを接続し、既存API clientとCSS変数・UI部品を使う。
`bun test`、`bun run typecheck`、`bun run lint`、`bun run build`で検証する。
320/768/1024/1440pxと短い横画面で一覧・controls・DL・削除確認が操作可能なことを確認する。
APIの所有者検査と空／失敗／中断／無期限の表示を、隔離した仮データと実ブラウザーで検証する。
