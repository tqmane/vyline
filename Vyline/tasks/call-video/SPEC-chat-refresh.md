# chat-refresh

目的: 青い注記で指定された位置から、ブラウザを再読み込みせずデータを取得する。

- 一覧のプロフィール行、チャットボタン左に「トーク一覧を再取得」。
- トークヘッダーの検索左に「このトークを再取得」。狭い画面でも表示する。
- 既存ストアの取得処理を使用し、選択中トーク・下書き・テーマを維持する。
- 取得中は状態を表示し、同じ操作の連打を防ぐ。失敗を通知し、既存データを消さない。
- 最新メッセージと着信の通常の自動同期も維持する。

対象: `sidebar.tsx`, `chat-area.tsx`, `icons.tsx`, `store.ts`, `store.test.ts`。
検証: 共通コマンド、失敗/下書き保持テスト、実ブラウザでボタンと新しいデータの反映を確認。
コマンド・スタイル・境界は `plan.md` に従う。
