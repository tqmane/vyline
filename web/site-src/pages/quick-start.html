前提

Docker Engine と Docker Compose v2 が使えるホストを用意します。公開コンテナは linux/amd64 と linux/arm64 です。

docker version
docker compose version

1. Compose ファイルを取得

mkdir -p vyline
cd vyline
curl -LO https://raw.githubusercontent.com/tqmane/vyline/main/docker-compose.yml

2. 起動

docker compose pull
docker compose up -d

既定ではホストの 3000 番ポートへ公開されます。

3. 状態を確認

docker compose ps
docker compose logs --tail=100 vyline
curl http://127.0.0.1:3000/healthz

/healthz が成功したら、同じホストのブラウザでは http://127.0.0.1:3000、別端末からは許可した到達経路のホスト名または IP とポートで開きます。

4. データの保存先

Compose の既定値では、作業ディレクトリの次の2つをコンテナへ bind mount します。

ホストコンテナ内容
./data/app/dataアカウント状態、設定、履歴、バックアップ関連データ
./storage/app/storageキャッシュ、保存メディア

5. LAN から使う場合

Compose の既定 bind は 0.0.0.0:3000 ですが、Vyline 側の LAN 機能は VYLINE_LAN_ACCESS=false が既定です。PC だけで使うなら bind address を 127.0.0.1 に絞れます。

VYLINE_BIND_ADDRESS=127.0.0.1
docker compose up -d

LAN や外部ネットワークから使う場合は、先に リモートアクセス を確認してください。

停止と再起動

docker compose stop
docker compose start

# コンテナを作り直す
docker compose up -d --force-recreate

docker compose down だけでは bind mount 先の ./data と ./storage は削除されません。逆に、この2ディレクトリを消す操作はデータ削除として扱ってください。
