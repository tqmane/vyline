入口は RPC_DICTIONARY

LINE.js のメソッド名、LINE Desktop で確認した根拠、Vyline 側の実装を対応付ける正本が Vyline/packages/protocol/src/dictionary/rpcMap.ts です。

// 調べたい機能
linejsName
  ↓
desktopEvidence
  ↓
stackApi
  ↓
domainApi
  ↓
backendApi

実装の層

場所役割
src/domain/VylineSession facade と上位 API
src/dictionary/RPC 名と Desktop evidence の対応
src/login/login、鍵管理、Desktop patch
stack/Thrift RPC、E2EE、低レベル通信

Desktop を根拠にする

新しい RPC や挙動を推測で追加せず、辞書の desktopEvidence と Desktop 解析結果を確認します。解析ツールは tools submodule にあります。

bun run vyline:check
bun run vyline:versions
bun run vyline:find-native -- <name>

E2EE

E2EE の低レベル実装は packages/protocol/stack/base/e2ee/mod.ts。メディア送受信では group key の準備、key material、plain fallback など複数経路があるため、UI 症状だけで protocol の失敗と決めつけず backend log と message metadata を合わせて確認します。

型

Thrift 型は vendored の @vyline/line-types を使います。protocol stack の型を更新する場合は bun run stack:types を利用します。
