Compose 側の変数

docker-compose.yml は、ホスト側の配置や公開範囲を環境変数で上書きできます。

変数既定値説明
VYLINE_IMAGEghcr.io/tqmane/vyline:latest起動する image
VYLINE_BIND_ADDRESS0.0.0.0ホスト側の待受アドレス
VYLINE_PORT3000ホスト側ポート
VYLINE_DATA_PATH./data/app/data の bind mount 元
VYLINE_STORAGE_PATH./storage/app/storage の bind mount 元
TZAsia/Tokyoコンテナのタイムゾーン

Vyline の主要変数

変数既定 / 例説明
VYLINE_HOSTCompose: 0.0.0.0backend の bind address
VYLINE_LAN_ACCESSfalseLAN 端末向けペアリング導線
VYLINE_TRUST_REMOTE_OWNERfalse保護済み到達経路でのみ使う owner 扱いの明示バイパス
VYLINE_DATA_DIRCompose: /app/data状態・履歴・設定
VYLINE_STORAGE_DIRCompose: /app/storage保存ストレージ
VYLINE_CORS_ORIGINdev: http://localhost:5173開発時の CORS 許可 origin
VYLINE_STATIC_DIRVyline/apps/desktop/dist本番 frontend build
VYLINE_DEVICEIOSIPADLINE 側のデバイス種別

設定例

PC ローカルだけで 8080 番を使い、データを /srv/vyline に置く例です。

VYLINE_BIND_ADDRESS=127.0.0.1
VYLINE_PORT=8080
VYLINE_DATA_PATH=/srv/vyline/data
VYLINE_STORAGE_PATH=/srv/vyline/storage
docker compose up -d

VYLINE_TRUST_REMOTE_OWNER

公開範囲を広げるためのスイッチではありません

Tailscale ACL、Cloudflare Access、認証済み reverse proxy などで「Vyline に届く前」に利用者を絞れている構成だけで使います。生の LAN / インターネット公開では有効にしません。

変更を反映

Compose の環境変数を変えたらコンテナを再作成します。

docker compose up -d --force-recreate
docker compose logs --tail=100 vyline
