初期化

git submodule update --init --recursive
git submodule status

先頭が - なら未初期化、+ なら親リポジトリが固定している commit と作業ツリーがずれています。

親から見えるのは commit

submodule の branch 名ではなく gitlink の commit SHA が Vyline に記録されます。子リポジトリで変更を push しただけでは親の参照は更新されません。

更新の流れ

# 子側で目的の commit へ進める
git -C Vyline/packages/protocol fetch
git -C Vyline/packages/protocol checkout <commit-or-branch>

# 親側で gitlink の差分を確認
git status
git diff --submodule

protocol 変更はアプリ本体への影響が大きいため、親側の typecheck / test まで通してから gitlink を更新します。

診断

リポジトリには submodule/workspace の状態をまとめて確認する bun run vyl:doctor があります。境界が分からない状態でファイルをコピーして直すより、まず実際の参照先を確認してください。
