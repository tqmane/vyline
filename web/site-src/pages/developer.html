必要環境

ルート package.json の engine は Bun >=1.4.0 です。submodule を含めて取得します。

git clone --recurse-submodules https://github.com/tqmane/vyline.git
cd vyline
bun install

開発サーバー

bun run dev

backend と frontend を同時に起動します。個別に触る場合は bun run dev:backend、bun run dev:frontend を使います。

確認

bun run typecheck
bun run lint
bun test
bun run build

Protocol / Desktop 解析

bun run vyline:check
bun run vyline:versions
bun run vyline:find-native -- <name>

cd Vyline/packages/protocol
bun run delta
bun run stack:types

Web Docs

このサイトの本文は web/site-src/pages/、ナビゲーション定義は web/site-src/content.json、共通 layout は web/site-src/build.py にあります。

python3 web/site-src/build.py

互換用にルートの scripts/build-web-docs.py からも同じ builder を呼び出せる構成にします。生成後は web/index.html と web/docs/**/index.html が更新されます。

変更の入口

新機能は docs/CONTRIBUTING.md の「辞書 → Desktop evidence → domain → BFF」の順に沿います。README は利用者向け入口であり、実装判断の正本にはしません。
