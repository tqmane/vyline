Backend

backend/src/api/line.ts は HTTP の入出力を受け持ち、ビジネスロジックは backend/src/service/lineService.ts に寄せます。セッション管理は backend/src/line/clientManager.ts、キャッシュや backup は backend/src/storage / backend/src/service に分かれています。

Protocol

packages/protocol は外部の @evex/linejs に依存せず、domain facade、RPC dictionary、login/E2EE、Thrift stack を持ちます。機能追加時は Protocol の探索順を使います。

データ

コンテナ運用では runtime data と media storage を image から分離し、/app/data と /app/storage へ保存します。UI の状態、backend の session、protocol の RPC は同じ永続化層ではないため、障害時はどの層で失敗しているかを分けて見ます。

Submodules

protocol、plugin、themes、Desktop 解析ツールは固定 commit の submodule です。main branch の先頭を自動追従する構成ではありません。
