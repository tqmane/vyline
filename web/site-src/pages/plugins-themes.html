Plugin

Vyline/packages/plugin は tqmane/vyline-plugin を submodule として参照し、plugin SDK と examples を持ちます。アプリ本体に feature-specific な拡張コードを直接足す前に、plugin 境界で扱うべき機能かを確認します。

Theme

Vyline/packages/themes は tqmane/vyline-theme submodule。VyTheme の preset と theme 関連資産を分離します。UI の主要トークンは CSS variables を前提にしています。

Submodule を含めて取得

git clone --recurse-submodules https://github.com/tqmane/vyline.git
cd vyline

# 既に clone 済みなら
git submodule update --init --recursive

更新

submodule は親リポジトリが commit SHA を固定します。子リポジトリの main が更新されても、親側の gitlink を更新しない限り Vyline の参照先は変わりません。

git submodule status
git -C Vyline/packages/plugin rev-parse HEAD
git -C Vyline/packages/themes rev-parse HEAD

API の参照

plugin API の説明は docs/plugin-api.md、theme API は docs/theme-api.md を正本として確認してください。
