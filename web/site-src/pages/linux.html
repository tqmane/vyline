必要なもの

Vyline 側で必要なのは Docker Engine と Docker Compose v2 です。配布イメージは GitHub Actions で linux/amd64 と linux/arm64 を同時に生成しています。

確認コマンド
CPU アーキテクチャuname -m
Dockerdocker version
Compose v2docker compose version

x86_64 は amd64、aarch64 / arm64 は arm64 image が選ばれます。

Docker の導入

Docker Engine のパッケージ名やサービス管理方法はディストリビューションごとに異なるため、このページでは Vyline と無関係なパッケージ手順を固定しません。Docker 公式の各ディストリビューション向け手順で Engine と Compose plugin を導入し、上の2コマンドが通る状態にしてください。

  • Docker Engine installation
  • Docker Compose plugin on Linux

Vyline を起動

mkdir -p vyline && cd vyline
curl -LO https://raw.githubusercontent.com/tqmane/vyline/main/docker-compose.yml
docker compose pull
docker compose up -d

systemd で Docker を使うホスト

Docker サービス自体の自動起動を有効にする場合は、Docker を導入した方式に合わせてサービスを有効化します。Vyline コンテナは Compose で restart: unless-stopped が設定されているため、Docker daemon が起動すれば停止指示を出していないコンテナは再起動対象になります。

保存先を変える

OS のルートディスクとは別の SSD やデータ領域へ保存したい場合は、Compose 実行前にホスト側パスを指定します。

VYLINE_DATA_PATH=/srv/vyline/data
VYLINE_STORAGE_PATH=/srv/vyline/storage
docker compose up -d

サービスユーザー、SELinux、ネットワークファイルシステムなどホスト側の制約がある場合は、bind mount 先が Docker から読み書きできることを確認してください。

公開範囲

同一マシンからしか使わない場合は VYLINE_BIND_ADDRESS=127.0.0.1 が最小です。LAN や外部公開が必要な場合は、単純にポートを開ける前に リモートアクセス を確認してください。
