Vyline とは

Vyline はセルフホスト可能なサードパーティ LINE クライアントです。ブラウザ UI、Bun/Hono のバックエンド、自前の LINE プロトコル実装をひとつのワークスペースで管理しています。

クイックスタートDocker Compose で起動する Linux一般的な Linux ホストで運用する Raspberry Piarm64 の Raspberry Pi で動かす Androidroot + real chroot の高度な構成

まず押さえる構成

Browser
  │
  ▼

  │ HTTP
  ▼

  │
  ▼

LINE services

Plugin、Theme、Desktop 解析ツールは別リポジトリを Git submodule として固定しています。どの submodule が何を担当するかは Submodules を参照してください。

データ

Docker では /app/data と /app/storage を永続化します。前者はアカウント状態や履歴・設定、後者はキャッシュや保存メディアに使われます。コンテナの更新とデータ削除は分けて考えてください。

次に読む

初回なら クイックスタート、既に起動できているなら 設定 と データと永続化 を確認してください。
