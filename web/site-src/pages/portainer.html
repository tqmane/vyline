使う Compose

リポジトリには Portainer の Stack 向けに docker-compose.portainer.yml があります。Vyline image、3000 番ポート、/app/data と /app/storage の bind mount、restart: unless-stopped が定義されています。

Stack を作る

  1. Portainer で対象 Environment を開き、Stacks → Add stack。
  2. Web editor に docker-compose.portainer.yml の内容を入れるか、Git repository から同ファイルを指定。
  3. 必要なら Environment variables で保存先・ポート・LAN 設定を上書き。
  4. Deploy the stack を実行。

よく使う変数

変数既定用途
VYLINE_IMAGEghcr.io/tqmane/vyline:latest利用 image
VYLINE_BIND_ADDRESS0.0.0.0ホスト側 bind
VYLINE_PORT3000ホスト側ポート
VYLINE_DATA_PATH./data永続データ
VYLINE_STORAGE_PATH./storage保存メディア等
VYLINE_LAN_ACCESSfalseLAN ペアリング機能

Portainer 自体の公開

Vyline より先に Portainer の管理画面を保護してください。Docker socket を触れる管理 UI を認証なしで外部公開する構成は避けます。外部から管理するなら VPN や認証済みリバースプロキシの内側へ置きます。
