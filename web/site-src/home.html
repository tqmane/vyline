VYLINE

LINE を、自分の環境で動かす。

Bun + Hono + React。Docker で動く、非公式のサードパーティ LINE クライアント。

はじめる ↗ ドキュメント
01 / RUN

Docker Compose で起動

公開イメージは linux/amd64 と linux/arm64。ローカルビルドは不要です。

$ mkdir -p vyline && cd vyline
$ curl -LO https://raw.githubusercontent.com/tqmane/vyline/main/docker-compose.yml
$ docker compose pull
$ docker compose up -d
02 / STACK
FrontendReact + Vite
BackendBun + Hono
Protocol@vyline/protocol
Storage/app/data · /app/storage
03 / WHAT'S HERE

クライアントだけではなく、運用まで。

履歴・メディアの永続化、バックアップ、Plugin / Theme、LINE Desktop を根拠にした独自 protocol stack を同じリポジトリで扱います。

履歴とメディア永続化とバックアップ↗ LINE protocolRPC 辞書と E2EE↗ 拡張Plugin と VyTheme↗
04 / NOTE

非公式クライアントです。

Vyline は LINE 公式製品ではありません。アカウント、セッション、保存データの扱いを理解したうえで利用してください。インターネットへ直接公開せず、外部利用時は到達経路を認証で保護します。
