Raspberry Pi

适用于运行 Raspberry Pi OS 64-bit 的 Docker 主机，并不限定某一个 Raspberry Pi 型号。

操作系统与架构

Vyline 发布了 linux/arm64 镜像，因此 Raspberry Pi 请使用 64 位 Raspberry Pi OS。当前 Compose 没有指定 32 位 ARM 镜像。

uname -m
# 预期: aarch64

硬件

Vyline 不会根据 Raspberry Pi 型号改变功能。实际差异主要来自内存容量、CPU 性能和存储 I/O。

条件影响
4 GB 或更多内存恢复大量历史记录或同时运行其他容器时更有余量。
约 1 GB 内存恢复和同步时更容易使用 swap，响应可能变慢。
microSDDocker layer、数据库、缓存和媒体写入集中在同一介质。
USB SSD / USB 存储更容易把持久数据或 Docker data-root 放到独立介质上。

Raspberry Pi OS 64-bit

sudo apt update && sudo apt full-upgrade -y
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker "$USER"
# 重新登录后
docker run --rm hello-world

这里使用 Docker 官方 convenience script。长期运维时，也请查看 Docker 针对 Raspberry Pi OS 的安装与更新说明。

存储

data/、storage/ 和 Docker layer 都会持续读写。如果历史记录或媒体很多，可考虑把持久数据放到 USB SSD 等外部存储，而不是只依赖 microSD。

df -hT
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS,MODEL

内存较少时

zram 或 swap 可用于避免 OOM，但恢复历史记录时如果发生大量 swap I/O，API 和 UI 响应也会变慢。约 1 GB 内存的设备建议停止不必要的容器，并观察恢复期间的内存与 I/O。

启动 Vyline

mkdir -p ~/vyline && cd ~/vyline
curl -LO https://raw.githubusercontent.com/tqmane/vyline/main/docker-compose.yml
docker compose pull
docker compose up -d
docker compose logs -f --tail=100

运维检查

  • 使用 docker compose ps 和 docker compose logs --tail=100 检查容器状态。
  • 使用 df -hT 检查保存 data/ / storage/ 的文件系统剩余空间。
  • 操作系统或内核更新后，确认 Docker 和 Vyline 能重新启动。
  • 不要把唯一备份也放在正在运行服务的同一张 microSD 上。
