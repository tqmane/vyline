更新与备份

更新 GHCR image，并备份主机侧的 data/ 与 storage/。

更新 container

docker compose pull
docker compose up -d

restart 会让现有 container 继续引用旧 image。应先 pull 新 image，再 recreate container。

备份对象

data/     -> account/session/settings/chat DB/restore state
storage/  -> cache/icons/saved media

data/ 包含 session、设置、聊天数据库、backup 等状态，因此恢复整个 host 时必须备份。要保留已保存媒体时，也应包含 storage/。

与 VylineBackup 的区别

设置里的 VylineBackup 是应用内部的 snapshot 功能，与用于恢复 Docker host 本身的 data//storage/ 主机级备份用途不同。

优先保证一致性的备份

docker compose stop
sudo tar -C . -czf vyline-backup-$(date +%F).tar.gz data storage
docker compose start

先停止 container 再复制，可避免聊天数据库等写入与主机侧复制并发。backup archive 可能包含认证信息，也要限制保存位置的访问权限。

恢复后的检查

  1. 确认 bind mount 目标与恢复前相同。
  2. 检查 container log 是否有 permission error。
  3. 确认登录状态与设置。
  4. 确认聊天历史与保存媒体。
  5. recreate container 后再次确认状态仍然存在。
