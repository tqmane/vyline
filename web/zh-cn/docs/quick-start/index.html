快速开始

使用已发布的 Docker 镜像启动 Vyline。这里的示例以仓库中的标准 Compose 配置为准。

非官方客户端

Vyline 不是 LINE 官方或获授权的客户端。请在理解对账号和数据可能产生的影响后再使用。

准备事项

  • 64 位 Docker 主机。公开镜像构建了 linux/amd64 和 linux/arm64。
  • Docker Engine 和 Docker Compose v2。
  • 用于保存持久数据的存储空间。

1. 获取 Compose 文件

mkdir -p vyline && cd vyline
curl -LO https://raw.githubusercontent.com/tqmane/vyline/main/docker-compose.yml
docker compose pull
docker compose up -d

标准镜像是 ghcr.io/tqmane/vyline:latest。容器内部监听 3000 端口，默认也发布到主机的 3000 端口。

2. 在浏览器中打开

http://127.0.0.1:3000

标准 Compose 的 VYLINE_BIND_ADDRESS 默认是 0.0.0.0，但 VYLINE_LAN_ACCESS 默认为 false。后端会拒绝来自非 loopback 地址的未认证访问。

只绑定到 loopback

在 .env 中设置 VYLINE_BIND_ADDRESS=127.0.0.1，然后重新创建容器。

3. 保护持久数据

标准 Compose 会把主机的 ./data bind mount 到 /app/data，并把 ./storage bind mount 到 /app/storage。

不要删除主机上的这两个目录

data/ 包含会话、设置、聊天数据库、备份等状态；storage/ 包含保存的媒体、缓存等数据。

4. 验证

docker compose ps
docker compose logs --tail=100

镜像带有针对 /healthz 的 healthcheck。更新时运行 docker compose pull && docker compose up -d，用新镜像重新创建容器。
