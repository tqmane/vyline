文档

Vyline 的安装、运维、内部机制和开发资料。第一次启动时，请从“快速开始”进入。

开始使用

快速开始使用 Docker Compose 启动，并确认存储位置和访问方式。Linux安装到普通 Linux 主机。Raspberry Pi在 Raspberry Pi OS 64-bit 上安装和运维。Android Docker Host将已 root 的 arm64 Android 设备作为 Docker 主机的入口。

按内容分类

安装、运维、内部机制和开发资料分别整理。设置值和支持功能以当前仓库实现为准。

实现参考

Docker 以 docker-compose.yml 和 .env.example 为准；通信层以 Vyline/packages/protocol 为准；插件以 Vyline/packages/plugin 为准。
