配置参考

把日常运维需要的设置与实现层面的高级配置分开说明。

先看 Compose

Docker 运维时，docker-compose.yml 中的替换变量是普通用户配置入口。Backend 内部调优变量不会和常规设置混在一起。

Compose 配置项

项目用途默认值
VYLINE_IMAGE使用的 container imageghcr.io/tqmane/vyline:latest
VYLINE_BIND_ADDRESS主机侧 published port 绑定地址0.0.0.0
VYLINE_PORT主机侧 Web 端口3000
VYLINE_DATA_PATH/app/data 的主机保存路径./data
VYLINE_STORAGE_PATH/app/storage 的主机保存路径./storage
VYLINE_LAN_ACCESSLAN/subdevice 访问行为false
VYLINE_TRUST_REMOTE_OWNER把受保护路径上的 remote browser 作为 ownerfalse
TZcontainer 内时区Asia/Tokyo
# 示例：仅在 localhost 发布
VYLINE_BIND_ADDRESS=127.0.0.1
VYLINE_PORT=3000
docker compose up -d

pull_policy: always、restart: unless-stopped、init: true、stop_grace_period: 30s 固定写在 Compose file 中。

Backend 常规配置

变量含义默认值
PORTBackend listen 端口3001；Compose 设置为 3000
VYLINE_HOSTBackend listen 地址通常为 loopback；Compose 使用 0.0.0.0
VYLINE_DATA_DIR账号状态、设置、DB、日志、备份等 rootBackend 的 data；Compose 使用 /app/data
VYLINE_STORAGE_DIRcache、已保存媒体等 rootBackend 的 storage；Compose 使用 /app/storage
VYLINE_CDN_CACHE_DIR把贴图等 CDN cache 放到其他路径VYLINE_STORAGE_DIR/cache/cdn-cache
VYLINE_MEDIA_CACHE_DIR保存媒体的兼容设置，在未配置 VYLINE_MEDIA_STORAGE_DIR 时使用VYLINE_STORAGE_DIR/saved-media
VYLINE_CORS_ORIGIN允许的 CORS origin，多个值用逗号分隔http://localhost:5173
VYLINE_STATIC_DIRBackend 提供的 Frontend buildVyline/apps/desktop/dist
VYLINE_DEVICEProtocol device modeIOSIPAD

VYLINE_LAN_ACCESS 与 VYLINE_TRUST_REMOTE_OWNER 的含义见 访问模型。它们属于认证/信任设置，与 bind address 分开。

实现层高级配置

下面变量确实会被 Backend 读取，但普通 Compose 使用不需要设置。只有在明确改变路径布局或 API 运维方式时才使用。

变量内容默认值
VYLINE_PUBLIC_HOST为 subdevice pairing 指定外部 host未设置时从 request 信息解析
VYLINE_API_ADMIN_SECRET管理 API（如 token 操作）认证；未设置时管理 API 关闭未设置
VYLINE_OPENAPI_PATH替换 /openapi.yaml 使用的 YAML 文件仓库 root 的 openapi.yaml
VYLINE_MAX_REQUEST_BODY_BYTESHTTP request body 上限与 backup storage limit 相同
VYLINE_PLUGIN_DIRplugin directoryVYLINE_DATA_DIR/plugins
VYLINE_LOG_DIR诊断与 message log directoryVYLINE_DATA_DIR/logs
VYLINE_BACKUP_DIRVylineBackup snapshot directoryVYLINE_DATA_DIR/backups
VYLINE_MEDIA_STORAGE_DIR已保存媒体 directoryVYLINE_STORAGE_DIR/saved-media
VYLINE_ICON_CACHE_DIR单独指定 icon cache 路径VYLINE_STORAGE_DIR/cache/icons
VYLINE_MEDIA_INDEX_PATHmedia index SQLite 路径VYLINE_STORAGE_DIR/media-index.sqlite

内部调优变量

VYLINE_SQLITE_*、VYLINE_BACKUP_HEAVY_*、VYLINE_CONTACT_*_TIMEOUT_MS 等是用于性能、容量与故障诊断的实现参数。它们会随代码和测试变化，因此这里不把它们固定成用户配置 API；需要时直接查看对应模块实现。

信息源

用户配置以 docker-compose.yml 与 .env.example 为准，高级配置以 Vyline/backend/src 实现为准。修改 Compose 环境变量后请 recreate container。
