Android host

Android

Android 端末を Docker ホストにする構成です。Vyline 自体は通常の arm64 image を使いますが、Docker を成立させるまでが一般的な Linux サーバーとは異なります。

root 済み端末向けです

real chroot、mount、loop device、iptables、dockerd など root 権限が必要な操作を使います。通常アプリや proot だけで完結する手順ではありません。

検証済みリファレンスと一般要件

現在の完全ガイドには OnePlus 9 Pro / Snapdragon 888 / Linux 5.4.254 QGKI 系カーネルでの検証実績があります。これは対応端末を OnePlus 9 Pro に限定する意味ではありません。

一般化できる要件は次の通りです。

  • arm64 / aarch64 Android
  • root shell
  • Docker に必要な namespace / cgroup / seccomp / network / storage 系 kernel feature
  • real chroot として使える Linux rootfs
  • Docker の data-root を置ける、OverlayFS と相性の良い filesystem
  • Android netd / policy routing と Docker bridge を共存させる network 設定

推奨構成

Android OS / vendor kernel
  ├─ root
  ├─ Termux                  # SSH / rootfs準備 / 起動スクリプト
  ├─ Ubuntu rootfs           # prootではなく real chroot
  │   ├─ dockerd
  │   ├─ containerd / runc
  │   └─ docker compose
  ├─ ext4 loop image         # /var/lib/docker
  └─ Docker containers
      └─ Vyline
          ├─ /app/data
          └─ /app/storage

proot の中で Docker を動かさない

proot-distro は Ubuntu rootfs の取得には使えますが、runtime は real chroot(2) を使います。runc / containerd は namespace、mount propagation、cgroup、device を kernel に直接要求するためです。

構築順

  1. Kernel 要件を確認する。
  2. Termux から Ubuntu rootfs を取得し、real chroot 用の mount を作る。
  3. /var/lib/docker を ext4 loop image へ置く。
  4. Ubuntu chroot に Docker Engine / Compose を入れる。
  5. hello-world、arm64、container outbound network を先に検証する。
  6. Android network を補正する。
  7. 最後に Vyline の arm64 image を起動する。
Vyline より先に Docker を単体で通す

docker run --rm hello-world と container からの外向き通信が通らない状態では、Vyline 側を調べても切り分けできません。

Android /data と overlay2

検証環境では Android の F2FS / casefold 上へ /var/lib/docker を直接置くと OverlayFS が EINVAL になりました。完全ガイドでは ext4 sparse image を loop device へ attach し、Ubuntu chroot の /var/lib/docker へ mount する構成を使っています。

SELinux

検証環境では loop image や mount 操作のため permissive を回避策として使いましたが、Docker の仕様として SELinux permissive が必須という意味ではありません。端末に合わせた sepolicy を用意できるなら、その方が防御を維持できます。

Vyline 自体は通常の arm64 image

docker pull ghcr.io/tqmane/vyline:latest

multi-arch manifest から arm64 image が選ばれます。Android 端末内で Vyline を source build する必要はありません。
