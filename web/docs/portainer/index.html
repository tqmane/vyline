Operations

Portainer

リポジトリには Portainer 用の Compose file があります。CLI 版と同じ GHCR image を使い、/app/data と /app/storage を bind mount します。

Stack を作る

  1. Portainer で対象 Environment を開きます。
  2. Stacks → Add stack を開きます。
  3. docker-compose.portainer.yml の内容を Web editor に貼ります。
  4. 必要な environment variable を設定します。
  5. Deploy the stack を実行します。

標準の Portainer Compose は ghcr.io/tqmane/vyline:latest、host port 3000、restart: unless-stopped を使います。

保存先を明示する

Portainer で相対 path の解決場所を意識したくない場合は、Stack の environment variable に絶対 path を設定しておく方が確認しやすくなります。

VYLINE_DATA_PATH=/srv/vyline/data
VYLINE_STORAGE_PATH=/srv/vyline/storage
Stack を作り直す前に path を確認

新しい Stack が別の空ディレクトリを mount すると、データが消えたように見えます。旧 Stack の bind mount 元を先に確認してください。

更新

latest を使っている場合でも、稼働中 container が自動で新しい image に切り替わるわけではありません。

  1. 新しい image を pull します。
  2. Stack を update / redeploy して container を recreate します。
  3. 稼働状態と logs を確認します。

Portainer の UI 名称は version により多少変わりますが、必要なのは「pull」と「recreate」の両方です。

Portainer Compose にある変数

変数標準値
VYLINE_IMAGEghcr.io/tqmane/vyline:latest
VYLINE_BIND_ADDRESS0.0.0.0
VYLINE_PORT3000
VYLINE_DATA_PATH./data
VYLINE_STORAGE_PATH./storage
VYLINE_LAN_ACCESSfalse
TZAsia/Tokyo

通常 Compose と完全に同じ変数集合ではありません。変更するときは、実際に使う docker-compose.portainer.yml を正本として確認してください。

Portainer 自体も保護する

Portainer は container の作成・変更ができる管理画面です。Vyline より強い権限を持つため、認証なしで Internet へ出さないでください。外部から管理するなら VPN などの閉じた経路を優先します。
