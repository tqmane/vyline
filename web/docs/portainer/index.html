Portainer

リポジトリのdocker-compose.portainer.ymlをPortainer Stackとしてdeployする手順です。

Stackを作成

Portainerは任意です

VylineはDocker Engineとdocker composeだけで起動・更新できます。Portainerは複数containerをGUIで管理したい場合に追加する管理画面で、Vylineの必須componentではありません。

Portainerを使う場合はStacksでdocker-compose.portainer.ymlの内容を使用します。標準imageはghcr.io/tqmane/vyline:latestです。

更新

  1. 最新imageをpullする。
  2. StackをUpdate / Redeployする。
  3. Vyline containerがrecreateされたことを確認する。
  4. data/とstorage/が同じbind mount先を使っていることを確認する。

Android real-chroot

Android real-chrootでは、bridge経由のpublished portがAndroid側routing/netfilterと噛み合わない端末があります。その症状がPortainerにも出た場合だけ、管理UIの切り分けとしてhost networkを使う方法があります。通常Linuxへ適用する既定設定ではありません。

docker volume create portainer_data
docker run -d \
  --name portainer \
  --restart=always \
  --network host \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v portainer_data:/data \
  portainer/portainer-ce:latest \
  --http-disabled
https://<host-ip>:9443
Docker socketの扱い

/var/run/docker.sockへアクセスできるPortainerはホスト上のcontainerを管理できます。管理UIは認証なしでInternetへ公開しないでください。
