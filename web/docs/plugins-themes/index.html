Plugins / Themes

Plugin と Theme は別の仕組みです。Plugin API は Beta で公開範囲を絞っています。Themes は VyTheme と preset の package として独立 submodule にあります。

Plugin API の現在地

Plugin は Vyline/packages/plugin の SDK を使う、信頼済みのローカル ES Module です。backend が Bun で TypeScript / JavaScript を動的ロードします。

現在利用できる主な機能:

  • アカウント単位の enable / disable と再起動後の復元
  • messages:read による受信メッセージ購読
  • settings:read / settings:write によるアカウント別 JSON 設定
  • activate / deactivate / handler の例外隔離

公開済み permission

permission現在の用途
messages:readctx.messages.on("message", ...) で受信 event を購読
settings:readctx.settings.get
settings:writectx.settings.set
型があることと runtime で使えることは同じではありません

messages:send、media:*、storage:*、network:request、ui:extend、notifications:send は、現在の plugin context には公開していません。

Plugin の置き方

各 plugin folder に manifest.json と index.ts / index.js を置きます。main が指定されている場合はその entry を使います。

{
  "id": "message-logger",
  "name": "Message Logger",
  "version": "0.1.0",
  "description": "受信イベントをローカルログへ記録します",
  "permissions": ["messages:read"]
}

repository には message-logger や settings-demo の example があります。まず同梱 example で permission と lifecycle を確認してください。

Plugin は sandbox ではありません

現在の設計は、信頼できるローカルコードを読み込むためのものです。署名検証、URL install、marketplace、browser UI extension は未対応です。第三者の plugin を「権限名が少ないから安全」と判断しないでください。

Themes

Vyline/packages/themes の実体は tqmane/vyline-theme です。@vyline/themes package として THEME_PRESETS と VyTheme 型を提供し、本体はそれを読み込みます。

現在の preset が持つ主要 token:

id, name,
accent, accentContrast,
bg, surface, surface2, sidebar,
text, textDim, border,
msgIn, msgOut, msgInText, msgOutText,
radius, chatBg, pattern

Theme を追加するときは submodule の src/index.ts に preset を追加します。Web Docs 側で「任意 CSS を hot reload できる」など、実 submodule にない API を仕様として増やさないでください。
