Configuration Reference

通常の運用で触る項目と、実装上の上級設定を分けて記載します。

まず Compose を見る

Docker運用では docker-compose.yml の置換変数が利用者向けの入口です。backend内部の調整用変数を、通常設定として並べることはしません。

Composeで設定する項目

項目用途既定値
VYLINE_IMAGE使用するコンテナimageghcr.io/tqmane/vyline:latest
VYLINE_BIND_ADDRESSホスト側で公開するアドレス0.0.0.0
VYLINE_PORTホスト側のWebポート3000
VYLINE_DATA_PATH/app/data のホスト側保存先./data
VYLINE_STORAGE_PATH/app/storage のホスト側保存先./storage
VYLINE_LAN_ACCESSLAN/subdeviceアクセスの扱いfalse
VYLINE_TRUST_REMOTE_OWNER保護済み経路のremote browserをownerとして扱うfalse
TZコンテナ内タイムゾーンAsia/Tokyo
# 例: localhostだけで公開する
VYLINE_BIND_ADDRESS=127.0.0.1
VYLINE_PORT=3000
docker compose up -d

pull_policy: always、restart: unless-stopped、init: true、stop_grace_period: 30s はCompose file側で固定されています。

backendの通常設定

変数意味既定値
PORTbackendのlistenポート3001。Composeでは 3000 を指定
VYLINE_HOSTbackendのlistenアドレス通常はloopback。Composeでは 0.0.0.0
VYLINE_DATA_DIRアカウント状態、設定、DB、ログ、バックアップ等のrootbackendの data。Composeでは /app/data
VYLINE_STORAGE_DIRcache・保存メディア等のrootbackendの storage。Composeでは /app/storage
VYLINE_CDN_CACHE_DIRスタンプ等のCDN cacheを別パスへ置く場合VYLINE_STORAGE_DIR/cache/cdn-cache
VYLINE_MEDIA_CACHE_DIR保存メディアの互換設定。VYLINE_MEDIA_STORAGE_DIR が未設定のとき参照VYLINE_STORAGE_DIR/saved-media
VYLINE_CORS_ORIGINCORS許可origin。複数はカンマ区切りhttp://localhost:5173
VYLINE_STATIC_DIRbackendから配信するfrontend buildVyline/apps/desktop/dist
VYLINE_DEVICEProtocol device modeIOSIPAD

VYLINE_LAN_ACCESS と VYLINE_TRUST_REMOTE_OWNER の意味は Access Model を参照してください。bind addressとは別の認証設定です。

実装上の上級設定

次の変数は実際にbackendが読みますが、通常のCompose利用では設定不要です。パス構成やAPI運用を意図的に変える場合にだけ使います。

変数内容既定値
VYLINE_PUBLIC_HOSTsubdevice pairingで外部向けhostを明示する未設定時はrequest情報から解決
VYLINE_API_ADMIN_SECRET管理API（例: token操作）の認証。未設定なら管理APIは無効未設定
VYLINE_OPENAPI_PATH/openapi.yaml で読むYAMLファイルを差し替えるリポジトリrootの openapi.yaml
VYLINE_MAX_REQUEST_BODY_BYTESHTTP request bodyの上限backup storage limitと同値
VYLINE_PLUGIN_DIRplugin directoryVYLINE_DATA_DIR/plugins
VYLINE_LOG_DIR診断・message logのdirectoryVYLINE_DATA_DIR/logs
VYLINE_BACKUP_DIRVylineBackupのsnapshot directoryVYLINE_DATA_DIR/backups
VYLINE_MEDIA_STORAGE_DIR保存メディアを置くdirectoryVYLINE_STORAGE_DIR/saved-media
VYLINE_ICON_CACHE_DIRicon cacheを別パスへ置くVYLINE_STORAGE_DIR/cache/icons
VYLINE_MEDIA_INDEX_PATHmedia index SQLiteのpathVYLINE_STORAGE_DIR/media-index.sqlite

調整用変数について

VYLINE_SQLITE_*、VYLINE_BACKUP_HEAVY_*、VYLINE_CONTACT_*_TIMEOUT_MS などは性能・容量・障害切り分け用の実装ノブです。値はコードとテストの変更に追従して変わるため、このページでは通常設定のAPIとして固定しません。必要なときは該当モジュールの実装を確認してください。

正本

利用者向け設定は docker-compose.yml と .env.example、上級設定は Vyline/backend/src の実装が正本です。Composeの環境変数を変えた後はcontainerをrecreateしてください。
