Configuration Reference

Composeと主要環境変数の実用リファレンス。

Compose側

項目用途推奨
imageGHCR imageghcr.io/tqmane/vyline:latest
pull_policyDeploy時のpullalways
portsWeb port3000:3000
/app/data状態/DB必ず永続化
/app/storagecache/media原則永続化
restartdaemon再起動unless-stopped

主要環境変数

変数意味例
VYLINE_HOSTアプリlisten host0.0.0.0
PORTコンテナ内port3000
VYLINE_DATA_DIR状態保存先/app/data
VYLINE_STORAGE_DIRstorage root/app/storage
VYLINE_LAN_ACCESSLAN/subdevice access modelfalse
VYLINE_TRUST_REMOTE_OWNERremote owner trustfalse
VYLINE_DEVICEProtocol device modeIOSIPAD
TZtimezoneAsia/Tokyo
