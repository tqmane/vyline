設定

Docker Compose の置換変数と、container / backend が読む環境変数は別です。通常のセルフホストでは Compose 側の変数だけ触れば足ります。

Compose から設定する値

標準 docker-compose.yml に実際にある値です。必要なら Compose file と同じディレクトリに .env を置きます。

変数標準値用途
VYLINE_IMAGEghcr.io/tqmane/vyline:latest起動する container image
VYLINE_BIND_ADDRESS0.0.0.0host 側の公開アドレス
VYLINE_PORT3000host 側の公開ポート
VYLINE_DATA_PATH./data/app/data の bind mount 元
VYLINE_STORAGE_PATH./storage/app/storage の bind mount 元
VYLINE_LAN_ACCESSfalseLAN / subdevice access の許可モデル
VYLINE_TRUST_REMOTE_OWNERfalse保護済み経路で remote browser を owner として扱う明示的 bypass
TZAsia/Tokyocontainer timezone

.env の例

VYLINE_BIND_ADDRESS=127.0.0.1
VYLINE_PORT=3000
VYLINE_DATA_PATH=/srv/vyline/data
VYLINE_STORAGE_PATH=/srv/vyline/storage
VYLINE_LAN_ACCESS=false
VYLINE_TRUST_REMOTE_OWNER=false
TZ=Asia/Tokyo

標準 container 内の固定値

Compose は backend に次の値を渡します。通常は host 側から上書きする必要はありません。

VYLINE_HOST=0.0.0.0
PORT=3000
VYLINE_DATA_DIR=/app/data
VYLINE_STORAGE_DIR=/app/storage

Dockerfile では cache / media の既定パスも /app/storage 以下へ寄せています。

VYLINE_CDN_CACHE_DIR=/app/storage/cache/cdn-cache
VYLINE_ICON_CACHE_DIR=/app/storage/cache/icons
VYLINE_MEDIA_STORAGE_DIR=/app/storage/saved-media

Docker を使わない開発時

ルートの .env.example には backend を直接起動するときの例があります。Compose の host-side 変数と混ぜないでください。

変数.env.example の例用途
PORT3001backend の listen port
VYLINE_HOST127.0.0.1backend の bind address
VYLINE_CORS_ORIGINhttp://localhost:5173Vite dev server など別 origin からの API access
VYLINE_STATIC_DIRVyline/apps/desktop/distbackend が配信する frontend build
VYLINE_DEVICEIOSIPADLINE protocol の device mode
.env.example は例です

コードや Compose と値が食い違う場合は、実際に利用している起動経路の設定を優先してください。

公開範囲を変えるとき

VYLINE_BIND_ADDRESS を変更するだけでは access policy の代わりになりません。LAN / Internet から使う場合は アクセス制御 と 外部アクセス を合わせて確認してください。
