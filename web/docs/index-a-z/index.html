A–Z Index

設定名、ファイル名、機能名から関連ページを引くための索引です。仕様そのものはリンク先と現在のソースコードを確認してください。

A

Access model — LAN access、remote owner trust、公開範囲。アクセス制御

Android Docker host — root 済み arm64 Android を Docker host にする構成。Android / 完全構築ガイド

Architecture — React/Vite → Hono/Bun → Protocol → LINE。Architecture

B

Bun — backend runtime と workspace package manager。Docker image は Bun 1.4.0 ベース。Developer Guide

C

Cloudflare Access / Tunnel — Internet から使う場合の認証・tunnel 構成。外部アクセス

Compose — 標準のセルフホスト方法。Quick Start / 設定

D

data / /app/data — session、設定、履歴などの persistent state。永続化

Device mode — VYLINE_DEVICE。既定は IOSIPAD。Protocol / E2EE

Docker healthcheck — container 内から /healthz を確認。Troubleshooting

E

E2EE / Letter Sealing — key import、送受信、group key handling。Protocol / E2EE

G

GHCR — ghcr.io/tqmane/vyline:latest。標準 image は linux/amd64 / linux/arm64。Quick Start

H

/healthz — Dockerfile の healthcheck が使う backend endpoint。Troubleshooting

L

Linux — Docker Engine / Compose が動く一般的な 64-bit Linux host。Linux

O

OBS — LINE の media upload / download 側を protocol が扱う領域。Protocol / E2EE

P

Plugin — trusted local ES Module。Beta。現在の公開 permission は message read と settings read/write が中心。Plugins / Themes

Portainer — Stack で Compose を管理する場合。Portainer

Protocol — Vyline/packages/protocol / tqmane/vyline-api。Protocol / E2EE

R

Raspberry Pi / SBC — arm64 Linux SBC。特定モデル専用ではない。Raspberry Pi / SBC

RPC_DICTIONARY — Vyline/packages/protocol/src/dictionary/rpcMap.ts。LINE.js 名、Desktop evidence、Vyline 実装の対応表。Protocol / E2EE

S

storage / /app/storage — saved media と cache の persistent root。永続化

Submodule — Protocol / Plugin / Themes / Tools の固定 commit。Submodules

T

Theme / VyTheme — @vyline/themes の preset type。Plugins / Themes

Tailscale / WireGuard — private network 経由の remote access。外部アクセス

Tools / vyline-search — Desktop version tracking、unpack、native symbol search、decompile 補助。Submodules

U

Update — Docker image は pull 後に container recreate が必要。更新とバックアップ

V

VYLINE_BIND_ADDRESS — host 側の published address。設定

VYLINE_DATA_PATH — host 側の /app/data bind mount 元。設定

VYLINE_LAN_ACCESS — LAN / subdevice access model。単なる listen address ではない。アクセス制御

VYLINE_PORT — Compose の host published port。既定 3000。設定

VYLINE_STORAGE_PATH — host 側の /app/storage bind mount 元。設定

VYLINE_TRUST_REMOTE_OWNER — 前段で強く認証済みの remote browser を owner として扱う明示的 bypass。アクセス制御

VylineBackup — Vyline 内の履歴 / メディア snapshot / restore。host の data/storage backup とは目的が違う。更新とバックアップ

W

Web Docs — web/ に直接 commit する static HTML。本文 generator は使わない。Developer Guide
