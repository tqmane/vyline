ドキュメント

導入と運用は Docker の実際の設定に、内部設計は現在のソースコードに合わせて説明します。まず動かしたい場合は Quick Start から進めてください。

最初に読むページ

Quick StartGHCR の image を Docker Compose で起動し、永続化まで確認します。 設定Compose の host-side 変数と backend の環境変数を分けて確認します。 ArchitectureReact / Vite → Hono / Bun → @vyline/protocol → LINE の境界を追います。 Troubleshooting起動、権限、ネットワーク、復元などを症状から切り分けます。

ホストを選ぶ

Vyline の標準 Compose が必要とするのは、対応する Docker image を実行できるホストです。通常の 64-bit Linux と arm64 SBC では同じ Compose を使います。Android は通常の Linux ホストと前提が異なるため、別ページに分けています。

ホスト読むページポイント
一般的な LinuxLinuxDocker Engine / Compose、service、firewall
Raspberry Pi / arm64 SBCRaspberry Pi / SBCaarch64、ストレージ、メモリ
Portainer 管理PortainerStack、image pull、recreate
root 済み AndroidAndroidkernel / cgroup / namespace / netd

運用

永続化/app/data と /app/storage に何が置かれるか。 更新とバックアップimage の更新、コンテナ再作成、bind mount の退避。 アクセス制御VYLINE_LAN_ACCESS と remote owner trust の扱い。 外部アクセスVPN、Cloudflare Access、認証済み reverse proxy の考え方。

内部設計と開発

LINE 通信を調べるときは本体だけでなく submodule も対象です。機能ごとの正本が分かれています。

Vyline/apps/desktopReact / Vite の UI と client-side state。
Vyline/backendHono API、service、session、storage、backup。
Vyline/packages/protocollogin、RPC、E2EE、OBS、Talk。submodule。
Vyline/packages/pluginPlugin SDK、permission、examples。submodule。
Vyline/packages/themesVyTheme と preset。submodule。
toolsDesktop LINE の version tracking、unpack、xref、decompile 補助。submodule。

Developer Guide と Submodules に開発時の読み順をまとめています。

非公式クライアントです

Vyline は LINE 公式・承認済みクライアントではありません。アカウント制限、セッション破損、データ損失などのリスクを理解した上で利用してください。
