見た目はシンプル。中身は、かなり深い。

Web UIの後ろには、Backend、独立したLINE protocol stack、E2EE identity、永続化、plugin runtime、theme package、Desktop解析ツールがつながっています。

01 · PROTOCOL

LINEとの境界を独立

QR / Email / Token login、device mode、Desktop headers、RPC、E2EE、Talk domainを専用submoduleへ分離。

02 · PERSISTENCE

履歴をコンテナの外へ

/app/data と /app/storage を永続化。recreateしても状態を維持。

03 · EXTENSIBILITY

Plugin & Themes

permission付きSDKと独立テーマpresetで、コアを直接いじらず拡張。

04 · ARM

PiもAndroidも

arm64 imageを提供。Androidはkernel/networkまで掘り下げた専用ガイドを用意。

05 · RESEARCH

Desktop更新を追う

version追跡、unpack、xref、decompile補助をTools submoduleへ。

ARCHITECTURE

機能ではなく、責務で分ける。

Browser ↓ Vyline Desktop UI ↓ Backend ── persistence / restore / media / plugin runtime ↓ @vyline/protocol ── login / transport / E2EE / Talk ↓ LINE services + @vyline/themes + @vyline/plugin-sdk + Vyline-Search
