UNOFFICIAL LINE CLIENT / MIT

LINEを、自分の環境で。

VylineはLINEの非公式サードパーティクライアントです。Web UI、Bun/Honoバックエンド、@vyline/protocolをDockerで動かし、状態はホスト側のdata/とstorage/に保存します。

セットアップを見る Docsを読む
~/vylinedocker compose
$ curl -LO https://raw.githubusercontent.com/tqmane/vyline/main/docker-compose.yml
$ docker compose pull
$ docker compose up -d
$ docker compose logs --tail=100
# http://127.0.0.1:3000
