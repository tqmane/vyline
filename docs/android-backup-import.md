# Android LINE バックアップの取り込み

設定の「詳細・復元」から、Android LINE の SQLite DB または PrtivateLEIN / LEINs 形式の ZIP を Vyline の現在のアカウントへ取り込めます。元ファイルは変更しません。

## 対応形式

- SQLite: 先頭が SQLite 3 で、`chat` と `chat_history` テーブルを持つ `naver_line` 系 DB
- ZIP: `databases/naver_line` と、任意で `chats/<chatMid>/messages/<localMessageId>` 以下の添付ファイルを持つ LEINs バックアップ
- 通常メッセージ、スタンプ、通話・参加退出等のシステム行、取り消し状態を会話履歴へマッピング
- 添付の本体とプレビューを別々に復元。本体が無い場合はプレビューだけを保持

取り込み先はログイン中アカウントです。DB 内の chat MID と message server ID を検証し、重複する server ID は最終状態へ統合します。端末内のローカル ID だけでサーバー ID がない行や、対応先を安全に確定できない添付はスキップします。

## 操作

1. Vyline に復元先の LINE アカウントでログインする。
2. 設定 → 詳細・復元 → Android LINE バックアップで「DB / ZIP を選択」。
3. 復元先アカウントと件数を確認して実行する。
4. 結果に表示される履歴、チャット、メディア、プレビューのみ、スキップ件数を確認する。

取り込みは既存履歴へマージされ、アップロードされた一時ファイルは成否にかかわらず削除されます。大切なデータでは、先に VylineBackup と元 Android バックアップを別媒体へ保存してください。

## セキュリティ上の制限

- ファイル種別を拡張子ではなく magic bytes で判定
- SQLite は read-only / query-only で開き、必要な固定クエリだけを実行
- ZIP の暗号化、危険なパス、重複 DB、CRC 不一致、重複・曖昧なヘッダーを拒否
- ZIP は最大 20,000 エントリ、展開後合計 4 GiB、圧縮率 200 倍まで
- 既定のアップロード / DB 上限 512 MiB、メディア 1 件 256 MiB
- 既定の読み取り上限は 50,000 チャット / 250,000 メッセージ

上限は `.env.example` の `VYLINE_ANDROID_*` で狭められます。インターネット公開時は大容量アップロード経路にも認証済みリバースプロキシの body size / rate limit を設定してください。

## 対応しないもの

- Android LINE アプリ本体への書き戻し
- E2EE 鍵が別途必要な暗号化本文の推測復号
- ハッシュ / HMAC があるだけで真正性が確認できない独自 ZIP の無条件受け入れ
- 添付が欠落している場合のネットワークからの自動再取得
